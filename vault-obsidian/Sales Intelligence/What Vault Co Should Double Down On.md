# What Vault Co Should Double Down On

The strong patterns from the legacy archive ([[Legacy GHL Messaging Lessons]]) + Vault Co's
differentiators ([[Vault Co Identity Core]]) — repeat and systematize these.

1. **Speed-to-lead.** Fast response to hot inbound is the #1 booking lever; make it a hard SLA.
2. **Specific-time booking offers.** "Tomorrow 9am or 1pm?" out-converts open-ended asks.
3. **Real seasonal urgency.** Storm-season / install-window framing tied to actual conditions.
4. **Outcome-anchored messaging.** Sell booked, qualified appointments + the system — not "leads".
5. **Operator positioning.** We run the system, not just "manage ads."
6. **Single, clear ask.** Short, human, mobile-readable.
7. **Transparent, human-approved actions.** High-trust is a differentiator — keep it.

These become the **Vault Co messaging standard** (a Command Hub recommendation from Vanessa) that
every executive drafts against.
